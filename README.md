# Sieve project website

Public project page for Sieve, our COMP 491 senior design project at Koç University. It is served by GitHub Pages from the `main` branch of this repo.

The source code is in a separate private repository. Nothing private goes here: no code, no keys, no internal notes.

To add a progress update, copy the template comment in `updates.html`, fill it in, and put it above the newest post.
